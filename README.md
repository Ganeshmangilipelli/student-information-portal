# Student Information Portal

## Preview

![Project Screenshot](assets/screenshot.png)

## Description

A full-stack Student Information Portal designed to improve academic communication and resource management through role-based dashboards, event management, book exchange, and student-teacher interaction modules.

---

## Features

- Student Authentication System
- Teacher Authentication System
- Role-Based Dashboard
- Event Management Module
- Book Borrowing / Exchange System
- Student-Teacher Communication
- Dynamic Content Rendering
- Responsive User Interface

---
